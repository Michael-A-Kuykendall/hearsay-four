Hearsay-IV interactive demo (WebAssembly, model-free)

closed vocabulary notice: this pipeline transcribes into a fixed closed vocabulary of 30 words (a CMUdict-shaped lookup table, phone strings only — not a model). Any utterance is aligned to the nearest-pronunciation entry by classical edit distance; out-of-vocabulary speech still resolves to the closest table entry, and the provenance tree below shows exactly which phones decided each word.
no-model guard: the scoring path contains no neural net, transformer, embedding model, or learned weights — classical techniques only (windowed features, Mahalanobis-ish phone scoring, hash-consed arena, commit window, edit-distance lexicon lookup, counted bigrams). The page decodes audio with WebAudio outside WASM; the module itself never touches the network or the filesystem.
