or that it is "model-free" (HMMs and n-grams are trained models; say "non-neural").

## 6. The shot-F problem and fix

`bash docs/demo/correction-demo.sh` works (all 4 fixes + undo verified), but each sentence prints
a huge one-line "why" JSON, and the run then continues into a slow 20-utterance collateral report,
so it can't be filmed. The fix: `HEARSAY_DEMO_VIDEO=1` in `hearsay-correct demo` runs only the
TRIFLE ODDS sentence, prints a one-line readable why, and skips the collateral report. The wrapper
is `docs/demo/video-correction.sh`. The full demo is unchanged when the variable is not set.
